# She Can Foundation

A responsive NGO website created for She Can Foundation, focused on women empowerment, career growth, leadership, and education opportunities.

## Features

- Responsive Design
- Modern UI/UX
- Hero Section
- About Section
- Career Opportunities Section
- Interactive Cards
- Smooth Animations
- Dark Mode Toggle
- Mobile Navigation Menu
- Scroll Reveal Effects
- Footer with Contact Information

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Design Highlights

- Women empowerment inspired color palette
- Gradient-based modern interface
- Responsive layout using Flexbox & Grid
- CSS animations and transitions
- Glassmorphism inspired navbar

## Responsive Design

The website is fully responsive and optimized for:
- Desktop
- Tablet
- Mobile Devices
